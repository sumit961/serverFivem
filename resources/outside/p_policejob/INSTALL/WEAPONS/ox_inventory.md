# ox_inventory — weapons

Paste the snippet below inside `ox_inventory/data/weapons.lua` (inside the `Weapons = { ... }` table).

```lua
['WEAPON_RADAR'] = {
    label = 'Radar Gun',
    weight = 1000,
},
['WEAPON_FLASHBANG'] = {
    label = 'Flashbang',
    weight = 1000,
    throwable = true,
},
```
