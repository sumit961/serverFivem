# v1.3.4 Free Camera Editor

The selector scene editor now has a Free Camera Mode.

Open editor:

```text
/charselectedit
```

Click **Free Camera Mode**.

Controls:

```text
WASD = move camera
Q/E = up/down
Mouse = rotate camera
Mouse wheel = FOV
SHIFT = fast movement
CTRL = slow movement
ENTER = save camera position/angle/FOV back to editor
BACKSPACE = cancel and return to editor
```

Shortcut:

```text
/csfreecam
```

After saving the camera in free cam mode, click **Save Scene** in the editor panel to persist it to:

```text
cm-characters/data/selector_scene.json
```
