# Custody monitoring

CM Law 2.8 adds a server-authorized Custody tab to the shared law dashboard.
The list is read directly from cm-prison and is visible only to on-duty
members with the prison-intake capability and cuffing permission. It includes
active prisoner count, character identity, booking reason, booking officer,
sentence duration, and release countdown.

The feature is read-only for field officers and does not create another prison
or intake system. All departments continue to use the same central cm-prison
resource.
