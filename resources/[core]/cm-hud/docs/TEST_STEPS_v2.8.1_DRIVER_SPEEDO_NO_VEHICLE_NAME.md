# Test Steps - CM HUD v2.8.1

1. Restart `cm-hud`.
2. Enter a vehicle as driver and confirm speedometer appears.
3. Move to/passenger seat or enter as passenger and confirm speedometer does not appear.
4. Exit vehicle and confirm speedometer stays hidden.
5. Enter a vehicle and confirm GTA's default vehicle-name popup does not show.
6. Equip a weapon and confirm GTA default ammo/weapon preview still does not show.
