# cm-doctor v2.1.0

- Purchased bandages, painkillers, antibiotics and adrenaline now update authoritative persistent health.
- Medkits restore the user to full health.
- When another player is nearby, a medkit can instead fully heal or revive that player in place.
- Medkits are consumed only after the server validates the player, distance, routing bucket and successful treatment.
- Failed treatment returns the consumed medkit.
