NV_CLOTH ADMIN CLOTHING UPDATE

Added/updated:
1. Admin bulk texture capture
   - Save Current Texture
   - Save Missing Textures
   - Save All Textures
   - Cancel bulk capture
   - Progress text during bulk capture

2. Saved/missing texture indicators
   - Admin texture list shows T0/T1/etc.
   - Saved textures show green/check.
   - Missing textures show red/cross.
   - Clicking a texture pill previews that texture.

3. Category-specific capture presets
   - Bags default to back capture.
   - Shoes default to feet camera and +0.28 Z offset.
   - Pants get slight +0.05 Z offset.
   - Earrings/watches default to side angles.
   - Admin can override angle: Auto, Front, Current Rotation, Back, Left, Right.
   - Admin can override Z offset.

4. Bag shared image support
   - Bags use shared image filename by default.
   - Saving a bag image creates male and female catalog rows using the same image.
   - Bag metadata saves bagLevel, backpackSlots, maxWeight, and snake_case aliases.

5. Capture camera improvements
   - New CreateSkinCamCapture helper.
   - Capture camera stays aligned to the studio/green screen.
   - Ped rotates for back/side screenshots without moving/rotating the green prop.

6. Shoe capture height
   - Capture temporarily lifts the ped by category/user Z offset.
   - Player position and heading are restored after screenshot.

7. Last captured preview
   - Admin panel now shows the last processed transparent PNG preview.

8. Safer green background removal remains active
   - Removes only true green-screen pixels.
   - Avoids the older edge fill that could remove dark clothes.

9. UI controls added
   - Capture angle selector.
   - Z offset input.
   - Shared male/female image checkbox for bags.
   - Texture saved/missing panel.
   - Save Missing / Save All / Cancel controls.

Install:
- Replace your existing nv_cloth folder with this one.
- Keep prop_ld_greenscreen_01.ydr inside nv_cloth/stream/.
- Restart nv_cloth and cm-items.
