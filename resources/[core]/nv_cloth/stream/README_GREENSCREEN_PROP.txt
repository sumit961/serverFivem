GREENSCREEN PROP NOTES

This resource uses the real L-shaped jim_g_green_screen_v1 prop for /clothingadmin.
It gives both a green vertical background and green ground/floor.

Keep these files:
- jim_g_green_screen_v1.ydr
- jim_g_green_screen_v1.ytyp

Do NOT put .ymap placement files in this stream folder. A .ymap auto-spawns the prop
in the world and can make duplicate/incorrect green props appear during admin capture.
The Lua code spawns and positions the prop itself.
