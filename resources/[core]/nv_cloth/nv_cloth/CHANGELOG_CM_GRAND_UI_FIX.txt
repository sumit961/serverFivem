CM Grand UI / Admin Creator Fix
================================

Summary
-------
Rebuilt the uploaded v2 UI behavior into two clear modes:
1. Normal Clothing Store: premium compact shop UI.
2. Admin Clothing Creator: full creator dashboard with capture tools.

Files changed
-------------
shared/config.lua
- Moved Headwear, Glasses, and Bags into the main clothing store category route.
- Removed Headwear, Glasses, and Bags from the accessory store.
- Accessory store now only uses earrings, chains, and watches.
- Increased generated color-wall size and distance for safer capture.

client/cl_shop.lua
- Added safer HUD state flags while clothing UI is open.
- Added inClothingStore player state.
- Improved cm-hud/cm_hud hide/show compatibility events.
- Hid native HUD/radar while clothing is open and restored it on close.
- Updated /clothShop test command to include headwear, glasses, and bags.

server/sv_cloth.lua
- Added inClothingStore state flag to server-side clothing/position-save block.

client/cl_admin.lua
- Admin studio no longer shows green screen/prop while simply browsing.
- Capture backdrop starts hidden by default.
- Added 'none' backdrop mode for clean admin browsing.
- Green mode uses the green prop.
- Blue/Magenta/White/Black use generated DrawBox wall.
- Generated wall remains larger/farther behind the player to reduce hand/arm clipping.

client/cl_capture.lua
- Capture now enables selected backdrop only for the screenshot.
- After screenshot, backdrop is hidden again unless preview is enabled by UI.
- Preview backdrop callback now spawns/uses the correct prop/wall when requested.

web/index.html
- Added admin/store mode helper text.
- Added Preview Capture Wall checkbox.
- Added capture note explaining Magenta for green clothes.
- Cache-busted app.js/style.css references.

web/app.js
- Fixed processed image save by sending imageBase64 to Lua.
- Added optional capture-wall preview logic.
- Background selector no longer forces the wall visible unless preview checkbox is enabled.
- Admin/store mode text and control behavior separated more clearly.
- Keeps capture background hidden by default while browsing admin items.

web/style.css
- Added clean Grand-RP-inspired luxury styling patch.
- Reduced empty feel with stronger panels, active states, better spacing, and responsive widths.
- Made admin right panel wider and more useful.
- Made normal store and admin creator visually separate.

Known limitations
-----------------
- FiveM/Cfx NUI and Lua behavior still needs in-game testing.
- HUD hiding depends on cm-hud supporting at least one of the provided events.
- Capture wall distance can be increased further if a very wide animation/pose clips into it.
