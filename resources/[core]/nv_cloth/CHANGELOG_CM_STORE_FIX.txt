CM Store Fix
============

Changed from the previous package:

1. Removed Bags from the normal player clothing store category list.
   - Bags remain available in admin for catalog/hidden/event workflows.
   - Bags are no longer rendered in player store categories even if old data passes it.

2. Kept Headwear and Glasses inside the normal clothing store.
   - Accessory store remains for earrings/chains/watches only.

3. Set normal clothing preview/dressing location to:
   vec4(-1197.2906, -778.9427, 17.3298, 128.0196)

4. Improved normal store UI spacing.
   - Right panel is now compact instead of a tall empty panel.
   - Selectors are grouped in a premium card.
   - Buy/action area sits closer to item details.

5. Added store-mode CSS class behavior.
   - Normal store and admin mode can now be styled separately.

Files changed:
- shared/config.lua
- client/cl_shop.lua
- web/app.js
- web/style.css
