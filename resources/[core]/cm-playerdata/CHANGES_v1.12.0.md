# cm-playerdata v1.12.0

- Adds Patch / Treat to G > Basic Actions for conscious players.
- Unconscious targets are treated immediately without consent and revived at full health.
- Conscious targets receive a 15-second Y/N treatment request before healing begins.
- Requires and consumes one `medikit`; legacy `medkit` is also accepted.
- Revalidates inventory, distance and player state when treatment finishes.
