# cm-playerdata v1.9.1 - Admin Noclip Label Hide

## Changed
- Player overhead labels now skip targets with `cm_admin_noclip = true`.
- Player G-menu targeting now ignores admins who are invisible in noclip.
- If the local player is admin-noclipping, playerdata hides overhead labels and G-menu targets for a clean admin view.

## Rules Preserved
- Server IDs are still never displayed.
- Visible ID remains database character ID only.
- Normal player identity privacy rules are unchanged.
