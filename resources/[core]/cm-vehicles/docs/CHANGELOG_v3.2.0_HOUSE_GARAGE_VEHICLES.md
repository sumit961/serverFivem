# cm-vehicles v3.2.0 — House garage vehicles

- Supports real networked cm-house garage vehicles.
- Garage cars are fully visible/collidable and can be entered with F.
- Starting the engine with Left Ctrl unfreezes the parked vehicle.
- G menu, ownership, keys, fuel, damage, tuning and state-bag identity work on garage cars.
- Stored garage entities are excluded from world-position persistence until they leave the garage.
