# Inventory Ammo Flow v3.7

- Manual reload is disabled.
- Ammo is stored in inventory only.
- Using ammo moves it to the ammo equipment slot.
- Using a weapon equips it to the weapon slot and moves the first matching ammo stack to the ammo slot.
- When the player shoots, the server consumes 1 ammo from the ammo slot.
- Armor use equips armor into the bodyarmor slot and applies armor to the character. Armor is not deleted on use.
