# Ammo / Reload

- Put `weapon_pistol` in the `weapon` equipment slot.
- Put `ammo_9mm` in the `ammo` equipment slot.
- Press `R`, use F8 command `reloadinv`, or right-click and choose Reload.
- Server consumes ammo from the ammo slot and adds ammo to the equipped GTA weapon.
