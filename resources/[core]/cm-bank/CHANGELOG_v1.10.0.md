# CM Bank v1.10.0 — Live Display Settings

- Added a settings button in the bank header.
- Added independent controls for overall UI scale and text scale.
- Added controls for warped texture visibility and cash-art visibility.
- Added an optional high-contrast mode and a one-click reset.
- Settings save locally for each player and are restored on the next bank visit.
- Display settings do not call the server or modify economy gameplay.
