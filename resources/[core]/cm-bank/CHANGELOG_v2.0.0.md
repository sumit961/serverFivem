# CM Bank v2.0.0 — Gaming Terminal Redesign

- Rebuilt the interface as a cohesive in-game financial terminal instead of a card dashboard.
- Added a secure-session header state and numbered banking modules.
- Reworked account balances into a layered command deck with directional geometry.
- Rebuilt the transaction area with a focused amount console and deliberate disabled states.
- Reworked recent activity into a compact live-system rail.
- Uses condensed display typography only for game-facing headings, actions, and balances.
- Uses a readable UI font for descriptions and supporting information.
- Removed the dot texture and retained restrained cash artwork.
- Preserved all existing NUI callback IDs, modals, payees, statements, ATM ownership,
  business history, display settings, and banking behavior.
