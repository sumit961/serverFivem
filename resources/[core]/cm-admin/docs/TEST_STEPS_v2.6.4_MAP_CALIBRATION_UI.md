# Test Steps - CM Admin v2.6.4 Map Calibration UI

1. Restart `cm-admin`.
2. Make sure your rank has `map.calibrate` or owner-level permissions.
3. Open `/admin`, then open the admin menu.
4. Go to **Map**.
5. Click **Calibrate Map**.
6. Use the bound inputs or nudge buttons until your admin map marker lines up with your GTA pause-map location.
7. Click **Save For Every Restart**.
8. Restart `cm-admin`.
9. Reopen the map and confirm the saved values are still used.
10. Optional: click **Copy Config** and paste the output into `Config.Map.Bounds` if you want the same values hardcoded in `config.lua`.
