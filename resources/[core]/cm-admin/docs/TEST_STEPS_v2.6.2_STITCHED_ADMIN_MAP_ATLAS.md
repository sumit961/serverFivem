# Test Steps - CM Admin v2.6.2

1. Restart `cm-admin`.
2. Open admin menu and go to **Map**.
3. Confirm the map background is the full stitched GTA map (same style as Climatime).
4. Confirm player blips appear at correct positions.
5. Toggle **Vehicles** and confirm vehicle blips appear in the correct area.
6. Toggle **Admins** and confirm logged-in admin blips still show correctly.
7. Use **Focus Self** and confirm the camera centers on your own position.
8. Click a nearby player blip and confirm it opens that player profile.
9. If you have permission, set a GPS waypoint and use **GPS TP** to confirm existing teleport logic still works.
