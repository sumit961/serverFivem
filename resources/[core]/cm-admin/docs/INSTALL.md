# CM Admin Noclip v1.4 Stand Fix

Install:
1. Delete old cm-admin folder.
2. Rename this folder to cm-admin.
3. Put it in resources/[core]/.
4. ensure cm-admin or restart cm-admin.

Commands:
- cmfly / noclip / fly: toggle noclip
- F2: toggle noclip
- cmunstuck: place player on safe standing ground
- cmstand: same as cmunstuck
- cmup 2: move up 2 meters
- cmsafe: teleport to Legion safe point
