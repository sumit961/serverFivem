# cm-ems v5.10.0

- Patient missions now use deterministic health-only condition briefings and varied patient models.
- Outdoor treatment scenes add lightweight local safety cones which are cleaned on stage change, cancellation, duty loss and resource stop.
- Hospital handoffs include a visible staff paramedic approaching the ambulance.
- Mission completion now reports a server-calculated S/A/B/C response grade and elapsed time without changing the existing reward.
- Existing mission NPC respawn/catch-up recovery remains active, with all new presentation entities included in cleanup.
