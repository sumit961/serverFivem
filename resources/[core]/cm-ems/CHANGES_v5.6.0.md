# CM EMS 5.6.0

- Added the Police-style in-place EMS wardrobe with a character camera,
  category selection, drawable selection, color selection, and drag rotation.
- Added five persistent favorite uniform slots per EMS character.
- Favorite outfits are stored by authoritative character ID and body type.
- EMS managers still control which clothing appears through the existing
  `org_ems` clothing catalog.
